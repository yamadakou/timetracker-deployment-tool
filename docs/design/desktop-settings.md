# 詳細設計: デスクトップアプリの設定の入力・テンプレート・クリップボードへのコピー（Phase 7e）

- 対象ブランチ: `feature/desktop-app`
- 状況: 論点はオーナーの回答で決めた（4）。一次情報の確認日は 2026-10-22
- 記録: `docs/REVIEW_ISSUES.md` の No.58

## 1. 目的
オーナーの Windows の実機での確認（2026-10-22）で、次の要望があった。

1. リソースグループを「設定」の画面で指定したい
2. 設定を Markdown の形式でクリップボードにコピーしたい
3. 「デプロイの設定」に名前を付けてテンプレートとして保存し、テンプレートを選んで入力したい
4. 設定の画面に「初期値に戻す」ボタンがほしい
5. 状態の確認で読んだ内容、削除の計画、ジョブの内容をクリップボードにコピーしたい
6. 削除でアプリ名を入力する欄の横に、Azure portal のように、アプリ名をクリップボードにコピーするボタンがほしい

## 2. 設計
### 2.1 対象の入力の場所（要望 1）
- 「サインインと対象」は、サインインとサブスクリプションの選択だけにする。リソースグループ・アプリ名・リージョンは「設定」の先頭（「対象」）に移す（オーナーの回答: 設定へ移す）
- ViewModel は変えない（`TargetViewModel` のまま。状態の確認・削除・デプロイの一覧もこの値を使う）。デプロイの一覧の「対象に入れる」は「設定」を開く

### 2.2 Markdown でのコピー（要望 2・5・6）
- 「設定」: 「Markdown でコピー」。対象・DB・スペック・永続化・利用可能期限・作るリソースの名前を表にする。パスワードは既定で伏せ字（「********（入力済み）」「（未入力）」）にし、「パスワードも含める」にチェックを付けたときだけ値を出す（オーナーの回答: 含めるか選べる）
- 「状態の確認」: 読んだ内容（環境・URL・永続化・注意・Container App の表）
- 「削除」: 計画（対象の表・警告・残すもの）
- 「ジョブ」: 題名・状態・手順・結果・エラー・注意・ログ
- 「削除」のアプリ名の入力欄の横: 「アプリ名をコピー」（確認に入力するアプリ名だけ）
- クリップボードには、デプロイの一覧のパスワードと同じく、履歴とほかの PC への同期に残さない形で入れる（`ClipboardContentOptions`。desktop-jobs.md の 6.4）。パスワードを含まない内容も同じ方法にする（扱いを 1 つにする）
- 表のセルの `|` と改行は、Markdown の表が崩れないよう `\\|` と空白にする

### 2.3 テンプレート（要望 3）
- 「設定」に「テンプレート」: 名前を入れて「テンプレートとして保存」、一覧から選んで「適用」、「削除」
- 保存するもの: サブスクリプション ID・リソースグループ・アプリ名・リージョン・DB 種別・DB 名・タグ・CPU とメモリ・永続化・利用可能期限日の決め方と日付（オーナーの回答: パスワード以外すべて）。パスワードは保存しない（desktop-app.md の Q4 を変えない）。適用してもパスワードの入力はそのまま
- 保存先: アプリのデータの `preferences.json`（同時に実行する数と同じファイル）。同じ名前があれば、確認してから上書きする。名前は前後の空白を除き、空なら保存しない
- 適用: サブスクリプションが一覧に無ければ（サインインしていない・権限が無くなった）、ほかの値だけを入れ、その旨を出す。保存した期限日が今日より前なら、設定の誤りに出る（既存の検証）

### 2.4 初期値に戻す（要望 4）
- 確認してから、リソースグループ（空）・アプリ名・リージョン・DB 種別・DB 名・タグ・パスワード・CPU とメモリ・永続化・利用可能期限を、起動したときの値に戻す（オーナーの回答: すべて戻す）。サブスクリプションの選択と同時に実行する数は変えない

## 3. テスト
- `Desktop.Core`: Markdown の内容（パスワードの伏せ字・含める、表のエスケープ）、テンプレートの保存・上書きの確認・適用（サブスクリプションが無い場合を含む）・削除・保存の失敗、初期値に戻す（確認で取り消した場合を含む）、状態・削除の計画・ジョブのコピー、アプリ名のコピー。分岐網羅率 100%
- `FilePreferences`: テンプレートの保存と読み直し
- UI テスト（CI）: 対象の入力が「設定」にあること、初期値に戻す、テンプレートの保存と適用（起動し直して確かめる）
