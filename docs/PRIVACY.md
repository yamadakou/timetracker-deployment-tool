# プライバシー ポリシー（TTDeployTool デスクトップアプリ）

> [!NOTE]
> Microsoft Store への提出（ポリシー 10.5.1）のための案です。提出の前に、発行元（Partner Center の開発者アカウント）の名前と問い合わせ先を確かめて公開してください。

最終更新日: 2026-10-27

## 1. このアプリが扱う情報
| 情報 | 使い方 | 保存する場所 |
|---|---|---|
| Azure のサインインの情報（アカウント名、テナントの識別子、アクセストークン） | 利用者本人の権限で Azure を操作するため（Microsoft Entra ID でサインインする） | 利用者の PC。サインインの情報はアプリのデータのフォルダーに、トークンのキャッシュは Windows のデータ保護（DPAPI）で保護して保存する（同じ Windows のユーザーでしか読めない）。サインアウトすると、アプリはサインインの情報を消し、次回は改めてサインインを求める |
| 入力した設定（サブスクリプション、リソースグループ、アプリ名、DB の種別、CPU とメモリなど） | デプロイの計画と実行のため | 利用者が名前を付けて保存したテンプレートと、まだ始めていない予定（デプロイ・削除）だけを、利用者の PC のアプリのデータのフォルダーに保存する（ほかは、アプリを終了すると消える） |
| 終わったジョブの記録（種類・対象のサブスクリプション・リソースグループ・アプリ名、予定・登録・予定の変更・実行開始・実行終了の日時、状態、失敗の理由、結果〔Timetracker の URL・DB のデータの保存先・利用可能期限・削除したもの〕、ジョブのログ） | ジョブの一覧で過去の結果を確かめるため | 利用者の PC のアプリのデータのフォルダー（`job-history.json`）。終わってから 180 日を過ぎたものと、新しい順に 500 件を超えたものは消す。利用者はジョブの一覧の「記録から削除」でいつでも消せる。パスワード・トークンは含めない。送信しない |
| DB のパスワードと Timetracker のパスワード | Azure Container Apps の secret として登録するため | 「予定に追加」したデプロイで、利用者が「予定をアプリの終了・再起動の後も残す」を選んだ場合（既定は選んだ状態）だけ、Windows のデータ保護（DPAPI）で暗号化して、利用者の PC のアプリのデータのフォルダーに保存する（同じ PC の同じ Windows のユーザーでしか復号できない）。そのデプロイを始めたとき・取り消したときに消す。ほかは保存しない（アプリを終了すると消える）。Dry-run では、利用者が選んだフォルダーの `.env` に平文で書き込む |
| 実行のログ | 進み具合と結果を表示するため（パスワードは含めない） | 画面の表示は保存しない（アプリを終了すると消える）。下の診断用のログにも書く |
| 診断用のログ（サインインとトークンの取得の結果、テナントとサブスクリプションの識別子と件数、Azure が返したエラー、アプリの例外） | サインインや読み込みがうまくいかないときの調査のため（パスワード・トークン・アカウント名は含めない） | 利用者の PC のアプリのデータのフォルダー（`logs`）。7 日で消す。送信しない（問い合わせのときに、利用者が選んで添付する） |

## 2. 情報を送る先
このアプリは、次のサービスとだけ通信します。開発者（発行元）のサーバーには、情報を送りません。利用状況の収集（テレメトリ）や広告も行いません。
- Microsoft Entra ID（サインイン）
- Azure Resource Manager（`management.azure.com`。利用者の Azure のサブスクリプションへのデプロイ・状態の確認・削除）
- Microsoft Store（アプリの更新の確認）

デプロイした Timetracker のコンテナは、利用者の Azure のサブスクリプションで動き、そのデータは利用者の Azure に保存されます。Azure と Microsoft Entra ID での情報の扱いは、[Microsoft のプライバシーに関する声明](https://www.microsoft.com/privacy/privacystatement) に従います。

## 3. 情報を消す方法
- サインアウトすると、アプリはサインインの情報を消します（保護したトークンのキャッシュは、有効期限が切れると使えなくなります）
- アプリをアンインストールすると、アプリのデータのフォルダー（テンプレート・予定・暗号化したパスワード・終わったジョブの記録・診断用のログを含む）が消えます。診断用のログは、「設定」の画面の「ログのフォルダーを開く」で開いたフォルダーから、いつでも削除できます
- 保存した予定（暗号化したパスワードを含む）は、「ジョブの一覧」で取り消すと消えます
- Azure に作ったリソースは、アプリの「削除」、または Azure ポータルで削除してください
- Dry-run で保存した `docker-compose.yml` と `.env` は、利用者が選んだフォルダーから削除してください
